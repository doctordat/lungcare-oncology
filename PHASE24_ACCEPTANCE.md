# Phase 24 — Care Passport

- [ ] Care Passport is positioned as a longitudinal patient-tracking / clinical decision-support summary, not an EHR.
- [ ] One deterministic Passport ID is derived per case for demo identity continuity.
- [ ] Passport summary reuses existing current treatment, imaging, structured biomarker, clinician decision and urgent/triage data.
- [ ] No duplicate treatment, imaging or biomarker source of truth is introduced.
- [ ] Patient, Doctor and Nurse can open the same longitudinal Care Passport summary for the active case.
- [ ] Clinical snapshot includes diagnosis, stage, current treatment, latest imaging response, biomarkers, clinician decision and recent urgent/triage events.
- [ ] Snapshot can be copied for demo handoff.
- [ ] UI explicitly states that cross-device QR/link sharing is not implemented in the static localStorage demo.
- [ ] Transferred/patient-reported data requires clinician verification.
- [ ] No autonomous diagnosis, prescription, EHR write or treatment selection is added.
