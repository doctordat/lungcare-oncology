# LungCare Oncology

Clinical decision support prototype for lung cancer longitudinal care.

> Prototype only. Recommendations are decision support and require clinician confirmation. This application does not replace HIS/EMR and does not autonomously sign medical orders.

## Phase 1

- Stable role workspaces: `/doctor`, `/nurse`, `/patient`
- Unified encounter state machine
- Outpatient return-visit flow
- Nurse intake and teach-back handoff
- Home-care medication adherence
- Urgent dyspnea alert flow
- Versioned treatment plan
- Local persistence with schema migration/recovery
- Demo patient only: Nguyễn Văn Minh (synthetic data)
