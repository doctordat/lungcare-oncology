# Phase 19 — Treatment explanation UX

- [ ] Doctor treatment step shows one visual explanation flow: clinical inputs → derived routing → option classes → clinician decision.
- [ ] Pathology, TNM 9, structured molecular context and safety review are visible as routing inputs.
- [ ] Stage IV structured molecular context shows driver-positive alteration(s) or no-driver PD-L1 TPS/bucket without inventing results.
- [ ] Routing blockers remain visible and prevent option cards when prerequisites are incomplete.
- [ ] Guideline source/version/date remain visible at the derived pathway.
- [ ] Recommendation cards remain option classes, not prescriptions.
- [ ] Current selected clinician option is visibly distinguished in the explanation panel.
- [ ] Existing/stale clinician decision state is visible with rationale.
- [ ] Explanation panel does not mutate treatment decisions or bypass existing readiness/audit checks.
- [ ] Responsive layout collapses to a single column on narrower screens.
- [ ] No drug, dose, regimen, order, autonomous recommendation or EHR write is created.
